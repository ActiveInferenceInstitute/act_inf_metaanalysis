# Visualization Guide

**Repository:** [github.com/ActiveInferenceInstitute/act_inf_metaanalysis](https://github.com/ActiveInferenceInstitute/act_inf_metaanalysis)

All 16 figures generated by `scripts/04_generate_figures.py`. Saved to `output/figures/` at 300 DPI with ≥16pt fonts using the colorblind-safe Wong (2011) palette.

---

## Style System (`visualization.style`)

The `VIZ_CONFIG` dictionary (in `style.py`) defines the global design system:

| Key | Value | Purpose |
| --- | --- | --- |
| `figure_size` | `(12, 7)` | Default figure dimensions |
| `dpi` | `150` | Base DPI (overridden to 300 by the figure script) |
| `tick_size` | `16` | Tick label font size |
| `font_size` | `18` | Body font size (16pt minimum enforced by `apply_visual_style`) |
| `title_size` | `22` | Title font size |
| `palette` | 8 hex colors | Wong (2011) colorblind-safe palette |
| `subfield_colors` | 8 domain → hex mappings | Per-domain color assignments |
| `grid_alpha` | `0.4` | Grid line transparency |
| `edge_color` | `#b0b0b0` | Network edge color |

All visualization modules import `VIZ_CONFIG` for consistent styling.

---

## Design and Accessibility Standards

All figures generated by this pipeline adhere to the **Active Inference Institute Visual Accessibility Standards**:

1. **Colorblind Safety:** All plots exclusively use the Wong (2011) colorblind-safe categorical palette in `VIZ_CONFIG["palette"]`. Do not hardcode custom hex codes.
2. **Readability Floor:** A strict 16pt font-size minimum floor is enforced across all visual elements (titles, tick labels, annotations). When building custom labels, you **must** use the `max(VIZ_CONFIG["font_size"] - X, 16)` rendering standard.
3. **High-Resolution:** All outputs are rendered at 300 DPI for press-ready scaling.

> See `src/visualization/style.py` for global runtime plot configurations.

## 1. Field Overview (`field_overview.py`)

### `field_summary.png`

Horizontal bar chart of paper counts per domain. Bars colored by `subfield_colors`. Count labels displayed inside/beside each bar.

**Input:** `subfield_classification.json`
**Function:** `plot_field_summary(total_papers, subfield_counts, output_path)`

### `subfield_distribution.png`

Pie chart of domain proportions. Domains with <2% share are grouped into "Other" for readability. Percentage labels shown on each slice.

**Input:** `subfield_classification.json`
**Function:** `plot_subfield_distribution(subfield_counts, output_path)`

## Temporal Plots (`visualization.temporal_plots`)

### `growth_curve.png`

Dual-axis chart: annual publication counts (bars) + cumulative total (line). Highlights inflection points in the field's growth trajectory.

**Input:** `temporal_analysis.json`

**Input:** `subfield_timeline.json`

## Citation Plots (`visualization.citation_plots`)

### `citation_network.png`

Spring-layout graph of the intra-corpus citation network. Node size scales with PageRank; highly cited foundational papers appear as hubs.

**Input:** `citation_graph.gml`
**Function:** `plot_citation_network(graph, output_path)`

### `degree_distribution.png`

Histogram of in-degree and out-degree distributions. The power-law tail is characteristic of citation networks.

**Input:** `citation_graph.gml`
**Function:** `plot_degree_distribution(graph, output_path)`

## Hypothesis Charts (`visualization.hypothesis_charts`)

### `hypothesis_dashboard.png`

Diverging horizontal bar chart showing citation-weighted evidence scores for all 8 hypotheses. Range: `[-1, +1]`. Green bars = supporting evidence, red bars = contradicting.

**Input:** `hypothesis_scores.json`
**Function:** `plot_hypothesis_dashboard(scores, output_path)`

### `evidence_timeline.png`

Multi-line chart showing cumulative evidence evolution per hypothesis over time. Divergent trajectories reveal which claims are gaining or losing support.

**Input:** `hypothesis_trends.json`
**Function:** `plot_evidence_timeline(trends, output_path)`

### `assertion_breakdown.png`

Per-hypothesis stacked bar chart breaking down assertion types (supports, contradicts, neutral). Shows the evidence composition for each hypothesis.

**Input:** `assertion_summary.json`
**Function:** `plot_assertion_type_breakdown(summary, output_path)`

### `assertion_summary.png`

Multi-panel summary: total assertion count, type distribution pie chart, and per-hypothesis totals. Provides a single-glance overview of the knowledge graph extraction results.

**Input:** `assertion_summary.json`
**Function:** `plot_assertion_summary(summary, output_path)`

## Advanced Plots (`visualization.advanced_plots`)

### `word_cloud.png`

Word cloud of corpus vocabulary sized by mean TF-IDF weight. Prominent terms reflect the field's core theoretical commitments.

**Input:** `tfidf_data.json`
**Function:** `plot_word_cloud(word_weights, output_path, max_words=100)`

### `pca_embeddings.png`

2-D PCA projection of TF-IDF document embeddings, colored by domain. Loading arrows indicate the top 8 vocabulary terms contributing most to each principal component.

**Input:** `tfidf_data.json`
**Function:** `plot_pca_embeddings(tfidf_matrix, labels, feature_names, output_path, n_loading_arrows=8)`

### `term_heatmap.png`

Heatmap of mean TF-IDF weight for the top 20 terms across domains. Darker cells indicate higher usage, revealing distinctive vocabulary per research area.

**Input:** `tfidf_data.json`
**Function:** `plot_term_heatmap(tfidf_matrix, feature_names, labels, output_path, n_terms=20)`

### `dendrogram.png`

Hierarchical clustering dendrogram of domain centroids using Ward linkage on mean TF-IDF vectors. Shows semantic proximity between research areas.

**Input:** `tfidf_data.json`
**Function:** `plot_dendrogram(tfidf_matrix, labels, output_path)`

### `topic_term_bars.png`

Faceted horizontal bar charts showing the top 10 terms per NMF topic. Reveals the vocabulary structure of each thematic cluster.

**Input:** `topics.json`
**Function:** `plot_topic_term_bars(topics, output_path)`

### `cooccurrence_matrix.png`

Symmetric heatmap of term co-occurrence across documents. Cell intensity reflects normalized document co-occurrence counts for the top 30 most frequent terms.

**Input:** `tfidf_data.json` (tokenized docs)
**Function:** `plot_cooccurrence_matrix(documents, output_path, n_terms=30)`

## Usage

```bash
# Generate all 16 figures
uv run python scripts/04_generate_figures.py

# Custom DPI
uv run python scripts/04_generate_figures.py --dpi 600
```

All plot functions return `output_path` after saving, enabling chaining in custom pipelines.
