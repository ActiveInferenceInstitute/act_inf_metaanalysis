# Visualization Module

Publication-ready figure generation for the Active Inference Meta-Analysis.

## Graphic Types

- **`style.py`**: Color management and consistent `VIZ_CONFIG` constraints.
- **`field_overview.py`**: High-level structural statistics and subfield distribution charts.
- **`temporal_plots.py`**: Cumulative corpus growth and YoY rates.
- **`citation_plots.py`**: Network topology mapping and degree distribution graphs.
- **`hypothesis_charts.py`**: Visualization of assertion strength and temporal evidence shifts.
- **`advanced_plots.py`**: Multivariate techniques including NMF matrices, dendrograms, PCA embeddings, and term heatmaps.

See [AGENTS.md](AGENTS.md) for charting guidelines and styles.
